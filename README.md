## Website

TanStack Start · React 19 · Tailwind v4

- Origin: Kecamatan Bayongbong, Kabupaten Garut (~1,500 ha shallot belt)
- Highland scallions: Cisurupan & Cikajang
- Products: Red Shallots (HS 0703.10), Green Onions (HS 0703.90)
- Pages: Home, About, Gallery, Products, Team, Blog, Contact + WhatsApp float

Contact details on the site are placeholders.

## Run locally

```bash
npm install
npm run dev
```
